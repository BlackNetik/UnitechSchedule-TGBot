# Unitech Schedule Bot

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/)
[![Telegram](https://img.shields.io/badge/Telegram-Bot-brightgreen)](https://core.telegram.org/bots)
[![Version](https://img.shields.io/badge/Version-2.0-orange)](https://github.com/BlackNetik/UnitechSchedule-TGBot)

Это Telegram-бот, который предоставляет расписание занятий для студентов Технологического Университета им. А.А. Леонова на основе данных с портала МИИГАиК (study.miigaik.ru). Бот скачивает и разбирает страницу расписания группы, поддерживает смену группы, отправку обратной связи и удобный интерфейс с кнопками.

Бот написан с помощью AI и предназначен для использования в личных чатах или группах. По умолчанию отображает расписание для группы ПИ-23.

> **Важно:** до версии 2.0 бот брал расписание со старого портала es.unitech-mo.ru через ICS-файлы. Этот портал перестал отдавать актуальное расписание, поэтому с версии 2.0 бот полностью переехал на study.miigaik.ru — расписание теперь скачивается как обычная HTML-страница и разбирается напрямую. Заодно из бота убран режим преподавателя (поиск и расписание по ФИО): на новом портале поиск преподавателя работает через динамическую подгрузку, которую пока не удалось изучить и перенести. Если понадобится — это можно добавить отдельно, когда будет пример того, что возвращает поиск на study.miigaik.ru/teacher/.

## Возможности

* Просмотр расписания на сегодня, завтра, неделю, следующую неделю или конкретный день.
* Смена группы по названию (например, `/change ПИ-24`).
* Отправка обратной связи разработчику.
* Логирование действий в файлах (директория Logs).
* Хранение пользовательских настроек в users.json.
* Обработка ошибок, включая таймауты и недоступность портала.

Настройки, оставшиеся у пользователей от старой версии (когда группа определялась через студента на es.unitech-mo.ru), бот доносит сам: при первом обращении после обновления он подставит группу по сохранённому названию через новый портал, а если название не найдётся — вернёт группу по умолчанию (ПИ-23). Отдельно ничего мигрировать не нужно.

## Требования

* Python 3.8 или выше.
* Зависимости (установите через pip):

```
pip install python-telegram-bot==20.7 httpx==0.25.2 beautifulsoup4==4.12.3
```

Или через файл зависимостей:

```
pip install -r requirements.txt
```

* Telegram API токен (получите у @BotFather).

## Установка

1. Клонируйте репозиторий:

```
git clone https://github.com/BlackNetik/UnitechSchedule-TGBot
cd UnitechSchedule-TGBot
```

2. Создайте файл `api_key_journal_unitech.txt` в корне проекта и вставьте в него ваш Telegram API токен (одна строка, без кавычек).
3. Установите зависимости (см. выше).
4. Запустите бота:

```
python rasp_unitech.py
```

Бот автоматически создаст необходимые файлы: `users.json` для хранения данных пользователей и директорию `Logs` для логов.

### Обновление бота

Для обновления бота до последней версии выполните:

```
git pull
docker build -t unitech-bot .
```

Затем перезапустите контейнер.

## Запуск в Docker

### Требования

* Docker Desktop (установленный на Windows/Mac/Linux)

### Способ 1: Через Docker Desktop (GUI)

1. Соберите образ:

   * Откройте Docker Desktop
   * Перейдите на вкладку **Images**
   * Нажмите кнопку **Build image**
   * Выберите папку проекта (где находится Dockerfile)
   * Введите имя образа, например: `unitech-bot`
   * Нажмите **Build**

2. Запустите контейнер:

   * Перейдите на вкладку **Containers**
   * Нажмите **Run** на вашем образе `unitech-bot`
   * В разделе **Optional settings**:
     * **Environment variables**: добавьте `TELEGRAM_API_KEY` = ваш_токен_от_BotFather
   * Нажмите **Run**

3. Проверьте работу:

   * Откройте вкладку **Containers**
   * Нажмите на `unitech-bot`
   * Смотрите логи во вкладке **Logs**

### Способ 2: Через командную строку

1. Соберите образ:

```
docker build -t unitech-bot .
```

2. Запустите контейнер:

```
docker run -d --name unitech-bot -e TELEGRAM_API_KEY=ваш_токен unitech-bot
```

3. Проверьте логи:

```
docker logs unitech-bot
```

### Способ 3: Через Docker Compose

1. Создайте файл `.env` в корне проекта:

```
TELEGRAM_API_KEY=ваш_токен_от_BotFather
```

2. Запустите:

```
docker-compose up -d
```

### Управление контейнером

* **Остановить:** `docker stop unitech-bot`
* **Запустить:** `docker start unitech-bot`
* **Перезапустить:** `docker restart unitech-bot`
* **Удалить:** `docker rm unitech-bot`
* **Просмотреть логи:** `docker logs -f unitech-bot`

### Важно: Переменные окружения

При запуске через Docker Desktop обязательно укажите переменную окружения:

* **TELEGRAM_API_KEY** — ваш токен Telegram бота (получите у @BotFather)

Без этой переменной бот не запустится.

## Использование

* Найдите бота в Telegram по его username (укажите при создании в @BotFather).
* Запустите `/start` для приветствия и меню.
* Используйте кнопки или команды для навигации.

### Доступные команды

* `/start` — Запуск бота и отображение меню.
* `/info` — Информация о боте, версии и командах.
* `/change <название группы>` — Смена группы (например, `/change ПИ-24`). Также доступно через кнопку "Изменить расп." в меню.
* `/today` — Расписание на сегодня.
* `/tomorrow` — Расписание на завтра.
* `/week` — Расписание на текущую неделю (с пометкой "верхняя"/"нижняя").
* `/next_week` — Расписание на следующую неделю.
* `/day <номер дня>` — Расписание на указанный день текущего месяца (например, `/day 15`).
* `/feedback` — Отправка обратной связи разработчику.

### Пример работы

После `/start` бот покажет меню с кнопками. Нажатие на "Расп. на сегодня" выведет форматированное расписание с номером пары, временем, типом занятия (лекция, практика, лабораторная и т.д.), преподавателем и аудиторией (с корпусом).

Для смены группы нажмите "Изменить расп." или отправьте `/change <название группы>` — бот найдёт группу на портале и переключит расписание на неё.

Если портал МИИГАиК недоступен (ошибка 504 или таймаут), бот сообщит об этом и предложит попробовать позже.

## Архитектура (простыми словами)

* **rasp_unitech.py** — Главный файл: запускает приложение, регистрирует хендлеры, кэширует username бота при старте.
* **handlers.py** — Обработчики команд и колбэков (start, info, change, feedback и т.д.).
* **study_portal.py** — Всё общение с порталом study.miigaik.ru: скачивание страницы расписания, разбор списка групп и занятий по дням, расчёт границ недели и "верхняя/нижняя неделя".
* **schedule.py** — Форматирование расписания (эмодзи по типу занятия, сборка сообщений на день/неделю) поверх данных из study_portal.py.
* **keyboards.py** — Генерация клавиатур (меню, выбор дня).
* **utils.py** — Утилиты: загрузка API-ключа, пользователей, логирование.
* **logging_setup.py** — Настройка логирования с ротацией файлов.
* **config.py** — Константы (версия, пути файлов, состояния диалогов, параметры портала: orgId, группа по умолчанию).

Бот использует `ConversationHandler` для многошаговых взаимодействий (feedback, выбор дня, смена группы). Всё асинхронно на базе `python-telegram-bot`.

Расписание группы на портале рендерится на сервере (Django), а не подгружается через JS, поэтому боту достаточно обычного GET-запроса `https://study.miigaik.ru/?orgId=2&groupId=<id>&dateStart=<пн>&dateEnd=<вс>` — из ответа разбираются блоки `.day-block`/`.lesson-block`. Список всех групп берётся из `<script id="groups-data">`, который присутствует на любой странице расписания.

## Логирование

Логи хранятся в `Logs/log-YYYY-MM-DD` (ротация ежедневно, хранение 30 дней). Формат: `timestamp - User ID (username) in chat ID: message`.
